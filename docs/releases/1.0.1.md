# 桌面歌词 1.0.1

## 更新内容

- 优化 Material 主页、中控台及小屏／横屏布局。
- 新增悬浮歌词粗细调节，支持 300–900 字重并记住设置。
- 预览与真实小窗共用渲染，修复透明背景偏灰及半透明／不透明背景的灰色外圈。
- 浅深主题切换保留歌词状态和设置滚动位置，减少重建闪烁。
- 主页支持补充翻译，按缺失行补齐并保留平台译文；新增翻译状态和失败提示。
- 修复歌词编辑保存按钮布局，并增加原生界面与翻译回归测试。

## 安装与升级

正式发布时，下载 `desktop-lyrics-1.0.1-arm64-v8a.apk` 安装。支持 Android 8.0 及以上的 64 位 ARM 设备。

正式包名仍为 `com.luoh.music.lrc`，沿用现有正式签名，可覆盖升级同签名的 1.0.0；`.dev` 测试包继续独立安装。`versionCode` 为 12。

`SHA256SUMS` 用于核对下载文件的完整性。双语显示与补充翻译的使用方式见[歌词外观与翻译说明](../lyrics-display.md)。
