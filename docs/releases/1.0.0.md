# 桌面歌词 1.0.0

由 [LuoH-AN](https://github.com/LuoH-AN) 维护的首个正式版本。

采用 Material 原生界面，完善主页中控台与桌面小歌词窗，更新项目信息和使用说明。

下载 `desktop-lyrics-1.0.0-arm64-v8a.apk` 安装即可。支持 Android 8.0 及以上的 64 位 ARM 设备。

正式包名为 `com.luoh.music.lrc`，使用独立正式签名；与 `.dev` 测试包可共存。如果设备中已有相同包名但不同签名的旧包，不能直接覆盖安装，请先备份需要保留的数据。

`SHA256SUMS` 可用于核对下载文件的完整性。
