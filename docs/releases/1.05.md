# 桌面歌词 1.05

这一版重点提升歌词数据的完整度、可纠错性和悬浮窗的长期使用体验。

## 主要更新

- QQ 音乐新增 QRC 逐字歌词与官方翻译，并保留普通歌词回退。
- 重构 QQ 音乐、网易云与 LRCLIB 的搜索、验证和评分流程，综合歌名、歌手、时长、专辑、版本、跨文字别名、逐字与翻译覆盖率选取结果。
- 单击歌词源可切源；双击会在当前来源重新匹配下一候选并记忆；长按可恢复自动匹配。失败不会替换当前歌词。
- 过滤标题、制作信息、平台占位提示与残缺逐字内容，避免把“有返回”误判成“有可用歌词”。
- 为平台限流和服务繁忙加入冷却，降低连续失败和无效请求。
- 新增中负载背景模式，只限制动态背景帧率，逐字歌词仍保持流畅。
- 优化播放控制、横屏布局、进度时间、滚动边缘渐隐和紧凑模式按钮自动淡出。
- 修复文本矩形痕迹、进度条异常光柱、状态圆点裁切及歌词切换时的轻微跳动。

## 安装说明

- 支持 Android 8.0 及以上。
- 正式 APK 仅包含 `arm64-v8a`，适用于绝大多数现代国产 Android 手机。
- 更新安装会保留原有设置、API 配置、翻译缓存和歌词偏移记忆。
- 应用不预下载离线翻译语言包；需要时可在应用内按需下载。
