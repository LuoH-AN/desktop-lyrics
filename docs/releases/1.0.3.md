# 桌面歌词 1.0.3

## 更新内容

- 维护版本：沿用 1.0.2 的界面与功能，未改动界面行为。
- 更新版本号并重新执行签名与校验流程，产出可覆盖升级的正式包。

## 安装与升级

下载 `desktop-lyrics-1.0.3-arm64-v8a.apk` 安装。支持 Android 8.0 及以上的 64 位 ARM 设备。

正式包名仍为 `com.luoh.music.lrc`，沿用现有正式签名，可覆盖升级同签名的 1.0.0 / 1.0.1 / 1.0.2；`.dev` 测试包继续独立安装。`versionCode` 为 14。

`SHA256SUMS` 用于核对下载文件的完整性。双语显示与补充翻译的使用方式见[歌词外观与翻译说明](https://github.com/LuoH-AN/desktop-lyrics/blob/main/docs/lyrics-display.md)。
