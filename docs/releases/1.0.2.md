# 桌面歌词 1.0.2

## 更新内容

- 去除悬浮歌词的文字阴影与光晕，收起、展开及设置预览保持清晰一致。
- 主页歌词换句加入 Apple Music 风格的柔和滚动、逐行错峰位移和高亮过渡。
- 改善快速切句、拖动进度与手动浏览时的动画衔接；系统关闭动画时直接切换。

## 安装与升级

下载 `desktop-lyrics-1.0.2-arm64-v8a.apk` 安装。支持 Android 8.0 及以上的 64 位 ARM 设备。

正式包名仍为 `com.luoh.music.lrc`，沿用现有正式签名，可覆盖升级同签名的 1.0.0 / 1.0.1；`.dev` 测试包继续独立安装。`versionCode` 为 13。

`SHA256SUMS` 用于核对下载文件的完整性。双语显示与补充翻译的使用方式见[歌词外观与翻译说明](https://github.com/LuoH-AN/desktop-lyrics/blob/main/docs/lyrics-display.md)。
