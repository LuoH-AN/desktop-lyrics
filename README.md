# 桌面歌词

简洁的 Android 桌面歌词应用，由 [LuoH-AN](https://github.com/LuoH-AN) 维护。

[下载 1.0.0](https://github.com/LuoH-AN/desktop-lyrics/releases/tag/v1.0.0) · [反馈问题](https://github.com/LuoH-AN/desktop-lyrics/issues) · [English](README_EN.md)

</div>

用原生 Material 界面，在桌面上同步显示正在播放的歌词。不需要额外账号，打开音乐播放器即可使用。

## 开始使用

1. 下载并安装正式版 APK。
2. 按提示授予通知使用权和悬浮窗权限。
3. 播放音乐，点击主页中控台「⋯」左侧的歌词图标开启小窗；具体调整在「⋯ → 设置」里。

需要 Android 8.0 及以上、64 位 ARM 设备和 Android System WebView。播放器需提供标准 MediaSession；如小窗被系统清理，请放宽应用的后台省电限制。

字号、粗细、背景与双语显示的区别，见[歌词外观与翻译说明](docs/lyrics-display.md)。
